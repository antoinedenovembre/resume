## [2026-10-08]
- Three resume styles built from the same YAML: `default` (original layout), `tech` (Times, date column on the left) and `sidebar` (colored left column)
- Sources reorganized per style (`src/styles/<style>/`, `build/<style>/`); the generator now emits layout-neutral macros
- Optional `short_name` for entries (used by the tech style when a heading is too long)
- Releases ship one zip per style
- CI split into compile / release / preview workflows
- Previous `latest` release archived as a release tagged `dd.mm.yyyy`
- Preview images auto-committed after a release
- README shows one preview per style; previews regenerated by CI
- Content proofreading (EN/FR) and localized "last updated" stamp

## [2026-04-20]
